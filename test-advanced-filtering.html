Filtering Logic Summary
✅ Include PR when:
  • Approval count < 3 AND
  • Current user has NOT approved it
❌ Exclude PR when:
  • Approval count >= 3 OR
  • Current user has already approved it
How to Test
  1. Open the PR Manager extension popup
  2. Add a repository URL (format: https://github.com/owner/repo/pulls)
  3. Add your GitHub token in the options page
  4. Click "Check Now" to see filtered PRs
  5. Only PRs with < 3 approvals that you haven't approved should appear
  6. The badge count should match the number of filtered PRs
Expected Results
✅ Badge Count: Should show only PRs that need your review (< 3 approvals & not approved by you)
📋 PR Overview: Should display approval counts like "2/3 ✅" for each PR
🔔 Notifications: Should mention "PRs needing review" with the filtering criteria
