  • Instant Access: Toggle filters without leaving the popup
  • Real-time Updates: PR list refreshes immediately when filters change
  • Synced Settings: Changes sync with the settings page automatically

💡 How it works:
• Checkboxes in the popup sync with the settings page
• When you change a checkbox, it saves to extension storage
• PR list automatically refreshes with the new filters
• Status message confirms the filter change
• Works consistently across all extension features
