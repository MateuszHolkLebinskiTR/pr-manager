# PR Manager Chrome Extension

This project is a Chrome extension built with Vite (vanilla JS). It monitors multiple GitHub pull request listing pages and notifies the user every hour (customizable) if PRs are pending for review. Key features include:

- Monitor multiple GitHub PR listing pages
- Chrome notifications for pending PRs
- Customizable notification interval
- GitHub authentication (OAuth/token)
- Support for private repos and organizations
- Customizable notification messages
- Export/import PR list
- MS Teams message generation
- Settings page
- Open source

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start development server:
   ```sh
   npm run dev
   ```
3. Build for production:
   ```sh
   npm run build
   ```
