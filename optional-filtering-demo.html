⚙️ PR Manager - Optional Advanced Filtering

✨ New Feature: Advanced PR filtering is now optional! You can enable or disable these filters in the extension settings.
🔍 Filter Option 1: Approval Count
Filter out PRs that already have 3+ approvals
❌ Disabled - Shows ALL PRs regardless of approval count
👤 Filter Option 2: My Approval
Don't show PRs you've already reviewed and approved
❌ Disabled - Shows ALL PRs regardless of your approval status
🎯 Combined Filtering Result
❌ No filters enabled - Shows ALL PRs from tracked users
How it works:
  • Both disabled: Shows all PRs (original behavior)
  • One enabled: Applies only that filter
  • Both enabled: PRs must pass both filters (AND logic)
📋 Example PR List
Sample PRs:
PR #1: New feature
0/3 approvals | Not approved by you
PR #2: Bug fix
2/3 approvals | Not approved by you
PR #3: Documentation
1/3 approvals | ✅ Approved by you
PR #4: Refactor
3/3 approvals | Not approved by you
Filtered Results:
All PRs shown (no filters applied)
🛠️ How to Enable
  1. Click the PR Manager extension icon
  2. Click "Settings" button
  3. Scroll to "🔍 Advanced PR Filtering" section
  4. Check the filtering options you want to enable
  5. Click "Save Settings"
  6. The extension will now apply these filters to:
    • Badge count (extension icon)
    • Popup PR list
    • Desktop notifications
    • PR overview/Teams messages
💡 Pro Tip: You can enable just one filter, both filters, or neither. The extension remembers your preference and applies it consistently across all features.
